# The third long run: the second's village, seed and switches, at 28-day
# years, with this week's changes to warnings and memory on. Started on
# 2026-10-12 at 05:34 after the second was stopped, on Scott's go-ahead, to see
# whether warnings that fade and cost little let the village feed itself.
#
# Against the second long run (results/long_run_v2), five switches differ:
#   - told_memory: villagers remember which news they shared with whom, and pass
#     on only what the listener has not had from them
#   - quick_warnings: a warning is a word to someone within reach, in one tick,
#     with no walk and no conversation
#   - bear_memory: memories are BEAR items, faded by the half-life of their kind
#   - fading_lessons: a lesson fades with the news it came from
#   - news_fades: the authored warnings fade with their news too, through BEAR
# The memory gene is off, so a difference from the second run is not also a
# difference in how long villagers remember.
#
# The build. Hearthwick d9c0f31 with BEAR 8e26162 from the WSL clone
# /mnt/c/tmp/bear-dev-main, which has items, the importance floor and the
# speed fix. The paper's frozen BEAR (5334e1e) predates items.
#
# The model is the first two runs': Qwen3.8-27B on the DGX Spark lane through
# the fleet gateway. The Spark's agent confirmed on 2026-10-12 that the server
# had not restarted, so all three runs used the same server, settings and seed.
# The embedder is 8360.
#
# From the repository in WSL:
#
#   PYTHONPATH=/mnt/c/tmp/bear-dev-main setsid nohup .venv/bin/python \
#     -m hearthwick run --days 8000 --days-per-year 28 --seed 1 --village greater \
#     --checkpoint-every 1 --no-designs --no-wants --no-search --no-vehicles \
#     --no-assessing --no-looking --no-placing --no-afar-news --no-bynames \
#     --no-leisure --no-living-memory --no-natural-talk --no-time-off \
#     --quick-warnings --told-memory --fading-lessons \
#     --llm-url http://192.168.1.176:9010/v1 --model Qwen3.8-27B-Spark-unsloth \
#     --llm-key-env THEMINDFOLD_API_KEY > runs/long_run_v3.log 2>&1 < /dev/null & sleep 45

#   PYTHONPATH=/mnt/c/tmp/bear-dev-main setsid nohup .venv/bin/python \
