## What it gets filed as

A fact's context tag is `knows_<kind>_<place>`, so the kind a listener assigns is what decides which instructions it can retrieve. Wording drift changes nothing a villager can do; reclassification changes everything it can do.

- facts descended from a witnessed event: **736**
